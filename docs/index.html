Installation

composer require ghostauth/ghostauth

Requires PHP 8.2+ (PHP 8.3+ recommended for full feature set).

Usage

Basic Authentication

use GhostAuth\AuthManager;
use GhostAuth\Providers\EmailPasswordProvider;

// Initialize the AuthManager
$authManager = new AuthManager($container);

// Attempt to authenticate
$result = $authManager->authenticate(
    new EmailPasswordProvider(),
    [
        'email' => 'user@example.com',
        'password' => 'provided_password',
    ]
);

if ($result->isValid()) {
    // Authentication successful
    $user = $result->getUser();
    // Set session, redirect, etc.
} else {
    // Authentication failed
    $errors = $result->getErrors();
}

Middleware Integration (PSR-15)

use GhostAuth\Middleware\GhostAuthMiddleware;

// In your middleware pipeline
$app->add(new GhostAuthMiddleware($authManager));

Basic Configuration

    'cookie' => [
        'name' => 'ghostauth_session',
